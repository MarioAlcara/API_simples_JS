# 🚀 API Express JS

API REST simples desenvolvida com Node.js e Express para demonstração de rotas e manipulação de dados.

---

## 🛠️ Tecnologias Utilizadas

* **Node.js**
* **Express**

---

## 💻 Como Executar o Projeto

1. Clone o repositório ou baixe os arquivos.
2. Instale as dependências executando no terminal:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   node index.js
   ```
